# 官網表單接 Google 試算表（一次設定，約 10 分鐘）

1. 用 onelifetaiwan@gmail.com 開一個新的 Google 試算表，命名「官網表單」。網址中 `/d/` 與 `/edit` 之間那串就是 SHEET_ID。
2. 在試算表上方選「擴充功能 → Apps Script」，把 `Code.gs` 內容整個貼進去，取代原本的程式。
3. 填入第 6 行 `SHEET_ID`。兩份方案 PDF 放到雲端、設「知道連結的任何人可檢視」，連結貼到 `PDF_LINKS`。
4. 右上「部署 → 新增部署作業 → 類型：網頁應用程式」。執行身分：我；誰可以存取：**所有人**。按部署，第一次會要求授權，照步驟同意。
5. 複製得到的「網頁應用程式網址」（結尾是 /exec），貼到網站 `assets/config.js` 的引號裡。

之後每筆表單會自動分頁寫進試算表（需求表／下載PDF／早鳥登記三個分頁），同時寄通知到 onelifetaiwan@gmail.com；下載 PDF 的人會收到含連結的信。

程式碼有改動時，要重新「部署 → 管理部署作業 → 編輯 → 版本：新版本」，網址不變。
