# ONELIFE 官網（靜態版）

- 純 HTML / CSS / JS，無需後端。任何靜態主機都能放（GitHub Pages、Cloudflare Pages、一般虛擬主機）。
- 頁面：index（首頁）、corporate（企業方案）、school（學校方案）、impact（影響力）、cases（案例總覽）、case-lotuspharm（單篇案例版型）、contact（報名與諮詢）、sitemap（內部用架構圖，上線前可刪）。
- 表單後端：見 `google-apps-script/README.md`。未設定前，表單會改用開啟郵件的方式備援。
- 照片：`photos/` 目前是從舊站截圖的低解析版（約 1300px 寬），正式上線請換原檔，檔名不變即可。
- 方括號文字（[人數]、[價格帶]）是待補資料，上線前請填上或刪除該行。
